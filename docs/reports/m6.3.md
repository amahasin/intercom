| #   | Request                     | Result                                                                                                                                                                                                                                                   |
| --- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Taskbar icon                | Windows get the multi-size `.ico`; an unpackaged run now has a Start Menu shortcut carrying its id and icon                                                                                                                                              |

## Tests

- `npx vitest run`: 159 pass (158 before). New: delete chat in the core (history gone, other side keeps theirs, replay does not restore it, a new message restarts the chat).
- `pnpm e2e` (36 tests): 34 passed in the full run. The two failures passed on rerun: the calendar test (the Playwright worker crashed with a Windows fast-fail code) and the relay-meeting test, which has been intermittent on this PC since M6.1 (also on the untouched M6 tag) and passed 3 of 3 afterwards. New: `m63-ui.spec.ts` (the setting reaches the main window, the title bar's theme source and a later call window; delete chat through the dialog; the Start Menu shortcut exists with the right id and icon).
- Light and dark screenshots of every main view were taken (`tests/e2e/screens.ts --theme=`); Playwright forces a light scheme unless `colorScheme: null` is passed, which hid the theme at first.

## Not verified here

- **The toast header and taskbar icon on screen.** The Windows toast cannot be captured by the tests; they check the shortcut that Windows reads. Windows can take a few seconds to notice a new shortcut, and an already running app keeps its old look until it is restarted.
- **Writing a Start Menu shortcut** is a side effect of every development run, tests included (one file, `InterCom.lnk`, id `InterCom.Desktop`). Delete it if you do not want it.
- **Delete chat** frees no disk space (the signed log stays, which is what keeps sync from fetching it back).
- **24-hour soak: running, not finished.** The previous run was stopped on purpose at about minute 8 (healthy: 50 online, 646 MB at minute 5) to rebuild. A new run on this final build started 2026-10-06 at 16:11 local through Task Scheduler (`InterCom-soak-24h`) and finishes about 2026-10-07 16:11. Its result is not in.
