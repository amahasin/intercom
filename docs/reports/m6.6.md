# M6.6 report: files at full speed, a call window like Teams, remote control that works, release 0.8.0

Date: 2026-10-06. Version: 0.8.0. Nothing is committed or tagged.

## What was asked, and the result

| #   | Request                                                        | Result                                                                                                                                                                                                                                                                                                           |
| --- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Send files at once from the composer; a setting to turn it off | Files go with Enter or Send. Receiving is automatic by default (messages under 10 minutes old); Settings > Files > "Receive files automatically" turns it off. Tested both ways (e2e, integration).                                                                                                              |
| 2   | Remove the 2 GB limit                                          | Limit is now 4 TiB. The manifest is paged (2048 hashes per page) and the "have" bitmap is written in a throttled way, so huge files do not stall. Free space is checked first. Integration test covers a file over 2 GB.                                                                                         |
| 3   | Participant cards overflow                                     | Cause: grid tiles had `height:100%`. Fixed; e2e checks every tile is inside the window.                                                                                                                                                                                                                          |
| 4   | Call controls on top, like the images                          | New top toolbar (timer, Chat, People, Raise, React, View, More, Camera, Mic, Share, Leave), "Request control?" dialog and the presenter card "X is requesting control: Deny / Give control".                                                                                                                     |
| 5   | Drag-and-drop cover stays after cancelling                     | The cover now clears itself when drag events stop, and on dragend/Escape. Tested.                                                                                                                                                                                                                                |
| 6   | Chat formatting buttons overflow in the call sidebar           | The toolbar wraps and the panel fills its space. Tested at the narrowest width.                                                                                                                                                                                                                                  |
| 7   | Noise cancellation                                             | Settings > Calls and the microphone menu: Off / Standard / High (default High). High adds a high-pass filter and a gate that lowers sound well below the user's own voice (about 24 dB) and turns automatic gain off. Gate logic unit-tested; quality by ear is **not** verified.                                |
| 8   | Screen share looks soft on fast LAN                            | Capture up to 4K at 30 fps, sender bitrate 25 Mbps with "maintain resolution", relay 8 Mbps. Not measured on two real PCs.                                                                                                                                                                                       |
| 9   | Remote control not working; pointer with two avatars           | Rebuilt around a native helper (`rcinput.exe`, SendInput, compiled at build time, shipped in resources). Moves are never delivered into InterCom's own windows; failures are reported instead of silent. Each side sees an arrow with a small avatar of whoever has a hand on it. Works for screens and windows. |
| 10  | Every side pane resizable                                      | List pane (main window) and call side panel (People / Chat): drag the edge, double-click resets, widths are remembered.                                                                                                                                                                                          |
| 11  | No soak test                                                   | Not run, and recorded as not performed in m6 to m6.5.                                                                                                                                                                                                                                                            |
| 12  | Build release                                                  | Done, below.                                                                                                                                                                                                                                                                                                     |

## Found and fixed while releasing

- `tests/integration` type-checked a renderer file as CommonJS with no DOM types. The pure noise logic moved to `calls/gate.ts`; the Web Audio plumbing stays in `calls/noise.ts`; `renderer/package.json` declares ESM.
- The remote-control e2e was flaky only because Bob's window shared the PC and sat over the middle of Alice's screen: his real pointer fed moves back to Alice. The test now moves Bob's window aside. Not a product defect (controller and sharer are on different PCs in use).
- 37 leftover test Electron processes (from killed runs) were loading the machine and causing call tests to time out; they were stopped.

## Compatibility

Peers on 0.7.x or older cannot read a file offer above 2 GB. Update everyone before sending very large files.

## Not verified

- Key injection (it would type into whatever has focus); control of a shared _window_.
- The arm64 installer was built but never run.
- Install and upgrade on a clean machine.
- Noise suppression quality by ear; screen quality and remote control between two real PCs.
- The 24-hour soak was dropped at the user's request, so the M6 done-when was never demonstrated.

Known flakes (not regressions): Playwright worker crash 3221226505; m6-scale relay test (intermittent, also on the m6 tag); m4-mesh under load; fuzz temp-dir EPERM right after an e2e run.
