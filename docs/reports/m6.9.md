# M6.9 report: call chat, temporary call group, Leave and End for everyone

The request: a spec of four parts and the question "do we have these features?". Answer before the work: only Personal Leave existed (the Leave button already took out only the person leaving). The rest was built.

| Spec item                                                                                                                     | Result                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. The call window's chat is the main chat                                                                                    | Done: `ChatPane` is drawn by both windows; the call window's old separate panel is now a title and a `ChatPane`. e2e checks the day line, typing line and composer, which the old panel lacked, and that text sent from the call window is in the direct chat. |
| 2. 1:1 call becomes a group call: the 1:1 chat leaves, a temporary group of everyone takes its place, updating as people join | Done: at three people the organiser's PC makes the group; all call windows swap to it; later joiners are added; leavers stay members.                                                                                                                          |
| 3. Temporary chat lifecycle                                                                                                   | Done: hidden from the chat list, badge, banners and calendar places while the call goes on; at the end of a PC's call it joins the list (all history and files) if anybody wrote in it, otherwise it is never shown; a late message revives a discarded one.   |
| Personal Leave                                                                                                                | Already there; now tested for three people (only the leaver's window closes, the others carry on).                                                                                                                                                             |
| 4. End call for everyone (organiser only)                                                                                     | Done: organiser-only menu on the Leave button with a confirmation; mesh and relay paths; everyone's media, sharing, remote control and window stop through the normal ended path, which also settles the chat. A request from anyone else is ignored.          |
| Extra                                                                                                                         | When the organiser leaves a mesh call, the person who was in longest becomes organiser (before, nobody had organiser controls).                                                                                                                                |

## Checks

- Typecheck, lint (2 old warnings), branding and origin checks: clean. Vitest: 185 passed (8 new). E2E: 21 passed across the call, chat, file and UI specs, including two new three-app call tests with screenshots.
- New tests: end for everyone (mesh and relay), a member cannot end it, leave in a call of three, organiser hand-over, the temporary chat is made once for all three and never shows in a chat list (not for an instant), unused chat never shown, written-in chat kept for all with its messages, a late message revives a discarded chat.
- Found by the tests: the relay host's request and notice schemas listed only `mute` and `remove`, so End for everyone would have silently done nothing in a large relayed meeting. Fixed and covered.

## Not verified

- Real camera and microphone media (the e2e uses fake media); remote control released across two real PCs when someone leaves (the local stop is tested, the other PC learns by the link closing).
- Four or more people in the browser tests (the add-a-fourth path is covered in the core tests only).
- A call with a PC on an older build (it ignores `end` and the chat id; documented).
- No version bump, no release build, nothing committed.

## Known limits

- An unused call chat leaves an invisible record in the logs of the people who were in the call (signed events cannot be taken back).
- Calls started in a group chat, and meetings, keep that group as their chat (no temporary group); large relayed meetings keep their host hand-over and have no organiser hand-over.
