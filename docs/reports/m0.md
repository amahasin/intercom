## What was built

- **Monorepo:** pnpm 11 workspaces; strict TypeScript 6 (`erasableSyntaxOnly`, `noUncheckedIndexedAccess`); ESLint with process-boundary rules (core has no Electron, renderer has no Node and reaches the core only via IPC, protocol is pure); Prettier; Windows CI.
- **packages/protocol:** beacon, wire envelope and the full message-type catalogue, session and profile bodies, link limits, signed profile, event envelope with the full event-type catalogue and the `msg.post` body, and the typed IPC API with its client. Also canonical JSON, base32 and base64url.
- **packages/core:**
  - Injectable `Clock`, `DiscoveryDriver`, `Dialer` and `KeyProtector` interfaces.
  - Crypto wrappers: ECDSA P-256, SHA-256, sign and verify over canonical JSON.
  - Self-signed X.509 certificates bound to the userId; 6-word safety phrase; signed, versioned profiles.
  - Identity lifecycle: generate, seal, reload; refuse a mismatched or missing key; recover a lost database from the key.
  - SQLite store with append-only migrations (FTS5 verified).
  - `CoreHost`, which serves the IPC API to any number of UI ports, including requests sent before start-up finishes.
  - Test doubles: `FakeClock`, `LoopbackDiscoveryHub`, an insecure test key protector.
- **apps/desktop:**
  - Main process: Mica window with title-bar overlay, per-profile data and single-instance lock, `officemesh://` app scheme, CSP, a session that blocks all web requests, navigation guard, and safeStorage key sealing on the core's behalf.
  - The core runs in a utility process.
  - The sandboxed preload exposes only the frame bridge.
  - The React and Fluent v9 renderer has a title bar (search placeholder, presence avatar), the six-item app rail, list pane, and identity card. It follows Windows light, dark and high-contrast settings, and all strings are externalised.
- **tools/sim:** N headless peers as bare Node processes (`pnpm sim --peers=N`), plus in-process peers on a shared loopback segment for integration tests.
- **tools/scripts:** no-network-origin build gate, branding check, protocol doc generator, icon generator (original mark, no image dependencies), packaged-app smoke test.
- **Packaging:** per-user NSIS installers for x64 and ARM64, with hardened Electron fuses. The packaged x64 build passes the smoke test.
