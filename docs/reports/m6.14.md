# M6.14: the ringtone is a recording (0.14.2)

- **Done:** the person being called hears `ringtone.mp3` (a run of 8 bell notes, 7.8 s, then 1.2 s of quiet) on the speaker chosen in Settings; the music-box tune stands in if the file cannot be decoded. Decision, fallback and the licence note: `docs/decisions.md` ("M6.14") and `LICENSE`.
- **Tried:** type-check, lint, the origin check, the packaged-app smoke test, the e2e tests for ringing and call windows (the ringing window plays the recording, not the stand-in), the full unit and integration suite.
- **Not tried:** how it sounds on real speakers (nobody here could listen to it). The source and licence of the mp3 were taken from its file name and have not been verified.
