## What was built

- **Protocol:**
  - Bodies for `msg.post` (mentions, reply, urgent, forwarded, link preview), `msg.edit/delete/react/unreact/pin/unpin/read` and `file.share` (with a signed chunk-manifest hash).
  - Wire `typing`, `file.have/manifest/request/cancel`, binary chunk frames and `avatar.get/data`.
  - 30 new IPC commands and events.
- **Core:**
  - Order-independent materialiser (messages, reactions, pins, receipts) plus `rebuild`.
  - Read state, unread counts and receipts; Activity feed (mentions, replies, reactions); saved messages.
  - Notification decisions (DND, urgent, mute levels, chat on screen).
  - FTS5 search.
  - Content-addressed file store with streaming import, verified chunk writes, resumable `.part` and bitmap, zone flag and safe open.
  - Multi-holder transfer manager with strikes.
  - LAN-only link previews; avatars; status-message expiry.
- **Desktop:** Windows toasts with inline reply and click-to-open; a tray with close-to-tray and Quit; a runtime-drawn taskbar badge; start with Windows (installed builds); serving downloaded images and avatars to the page; opening files and showing them in Explorer; the snipping tool.
- **UI:**
  - Lexical composer: formatting toolbar, Markdown shortcuts, @-mention menu, emoji picker, urgent, attach, paste, snip, drag-and-drop, link preview card, reply and edit modes.
  - Safe Markdown renderer.
  - Message hover actions and menu; reactions; reply quotes; edited, deleted and forwarded markers; pins list; notification level per chat.
  - File cards with progress, and inline images.
  - Activity pane (All, Unread, Saved); title-bar search with highlighted snippets that jumps to the message.
  - Unread badges on the rail and chats; Settings (read receipts, start with Windows, profile picture) and status expiry; "Seen" status.

## Tests

- 94 unit and integration tests (Vitest).
- 13 Electron end-to-end tests (Playwright), on a private loopback LAN.

## Bugs found and fixed during M2

- **One request per chunk tripped the plan's 50-frames-per-second abuse limit.** The holder banned the downloader and the transfer stalled at 182 MB. It is now batched, with a 16-chunk request at most about 13 times a second.
- **Downloads marked unavailable never retried** if the holder returned within the offline window. They now re-ask every 5 s.
- **`rebuild` wrote while iterating the log**, which better-sqlite3 forbids. It now pages through the log.
- **An ambiguous `kind` column** broke the conversation list after the migration.
- **The zone flag was written asynchronously**, racing the completion signal. It is now synchronous.
- **Inline images were stretched.**
- **React Compiler violations in the composer** (mutating a ref passed as a prop, refs read in render) were restructured rather than suppressed.

## Deferred, and why

- **Files rail (Recent, Downloads) and the channel Files tab:** M3, built from `file.share` events. **"Upload an edited copy as a new version":** M3.
- **Settings page sections** (Devices, Files location, cache size and clear-cache, Network): the cache and space-used UI moves to M3 with the Files rail. Devices goes with calls in M4.
- **Read receipts in groups of up to 20; channel default "mentions only":** with groups and channels in M3. The code already handles the channel default.
- **Toast Accept/Decline for calls; missed calls and team invites in Activity:** M4 and M3.
- **Owner decision 2 (database encryption)** is unchanged. The chat database, now holding rich content and file metadata, is still unencrypted at rest.
