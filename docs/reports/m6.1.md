Fourteen changes from using M6. Not a plan milestone; no version bump or installer was built for it (the code reports 0.6.0).

## Bugs found while testing

- **Parallel chunks leaked file handles** (`FileStore.handle` cached the handle after an `await`, so two chunks of one file could open it twice). Fixed; the "Closing file descriptor on garbage collection" warnings in the test run are gone.
- **The call-ended message could be wiped** by a call update queued before the call ended (a callee in Do not disturb). Calls that have ended are now ignored by late updates.

## Tests

- `npx vitest run`: 153 tests pass (134 before). New: file store without copies, missing files, progress (`Meter`), calendar maths.
- `pnpm e2e` (29 tests): 28 pass in the last full run. New: `tests/e2e/m61-ui.spec.ts` (attach and send a 1 GB file with progress, speed, missing states and no copy; call sounds and end screens; Settings categories and profile; calendar slot, right-click, filters and views; 960 px column and per-rail panes). Older specs were updated for the view menu, Settings categories, queued attachments and the recordings folder.
- `pnpm lint`: no errors (two React Compiler warnings about TanStack Virtual). `check:origins` and `check:branding`: clean.

### Known flakes on this PC

- `m4-mesh` (8 people for 1 minute) failed in two of three full runs and passed alone four times. Late in a long run, eight Electron apps share the CPU with the previous test's shutdown. It needs a quiet machine.
- `m6-scale` "outgrows the mesh": in one run the relay host got no audio (video fine). It failed four times in a row, also on the untouched `m6` tag, and then passed in the next full run, so it is not caused by this batch. Its cleanup also threw `EPERM` and hid the real error; `tempDataRoot().dispose` now ignores that.

## Not done, and risks

- The 2 GB per-file limit is unchanged. Raising it means paging the chunk manifest.
- Opening the firewall for Public networks widens exposure on cafe or guest Wi-Fi. Every connection still needs mutual TLS and signed messages, but the ports answer. Offices who want the old behaviour can remove the Public profile from the rules in Windows Firewall.
- Sounds were checked by their log (`window.officemeshSounds`), not by listening; the tune itself needs a human ear.
- **24-hour soak: not finished on this code.** Runs on the M6 and M6.1 builds were killed early from outside (see `m6.md`). The soak is now running on the M6.2 build; see `m6.2.md`.

> **Later:** the 24-hour soak mentioned in this report was stopped and will not be run; see `m6.6.md`.
