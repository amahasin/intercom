## What was built

- **Protocol:**
  - Bodies for `meeting.schedule`, `meeting.update`, `meeting.cancel`, `meeting.rsvp`, `call.started` and `call.ended` (the types were reserved in M0).
  - Wire `call.join`, `call.reaction` and `call.control` (capability `calls.meet`).
  - Optional roster fields for raised hand, recording and spotlight; an explicit meeting flag on invites.
  - 14 IPC commands and 3 events.
- **Core:**
  - Meeting cards, RSVPs, cancellations and "meeting over" in the materialiser (migration 7).
  - Calendar occurrences (daily, weekdays, weekly, with an end date); 15-minute reminders; .ics export.
  - Meet now, joining through online members, and the same meeting started twice merging into one call.
  - Open calls that stay up while anyone is in them; organiser controls; reactions.
  - Recordings received in pieces and shared to the chat.
- **Desktop:**
  - MediaPipe runtime and model bundled, with its telemetry removed at build time.
  - WebAssembly allowed by the CSP; inline video playback with byte ranges.
- **UI:**
  - Calendar rail (day, work week, week; meeting details with join, RSVP, .ics and cancel); New meeting dialog; upcoming list.
  - Meeting and "meeting started" cards in chats; Meet now in group chats and channels.
  - In a call:
    - raised hands, live reactions, and organiser menus (mute, remove, spotlight; mute everyone);
    - gallery and speaker views, and switching devices mid-call;
    - background blur, recording with banner, meeting chat beside the call, and the whiteboard (pen, rectangle, ellipse, text, sticky notes, share as PNG).

## Tests

- 126 unit and integration tests (Vitest, 26 files). New: 5 meeting tests covering the offline invitee, RSVPs, cancellations, organiser-only changes, rebuild, reminders and .ics, Meet now and joining, a double start merging, and organiser controls and reactions.
- 21 Electron end-to-end tests (Playwright), including the 3 new M5 tests.
- `pnpm build` (no network origins) and lint pass; `pnpm dist` builds the 0.5.0 installers and the packaged smoke test passes.

## Bugs found and fixed during M5

- **An infinite render loop crashed the call screen.** A store selector built a new array on every call, so React saw endless changes. It now selects the stable array and filters outside the selector.
- **Blur never started:**
  - MediaPipe picked its non-SIMD build, which was not bundled.
  - The page's own meta CSP (stricter than the header) blocked WebAssembly.

  Both are fixed: the SIMD build is named directly and both policies allow `'wasm-unsafe-eval'`.

- **Blur's automatic switch-off never fired.** It compared its output rate with the frames it read, which fall together when frames are dropped; it now uses the camera's own frame count.
- **A struggling blur froze the page.** It now yields between frames.
- **Recordings could not play in the app.** The custom scheme lacked the `stream` privilege and the files route served images only. Both are fixed, with byte ranges for seeking.
- **MediaPipe would have sent usage statistics to Google every minute.** The session blocks the request anyway, but the code is now removed at build time.
- **Earlier tests:** the M1 chat test set the rich-text editor with `fill()`, which sometimes did not register; it now types. The M4 test was updated for Hold's move into the More menu.

## Known limitations

- **CPU test noise:** the 200-colleague CPU test read 3.4% once, right after the heavy call tests, and passed twice when repeated on its own. It measures the core process, which M5 did not change on that path.
- **Long whiteboard sessions:** the whiteboard's history grows with every pen movement for the length of a call; a board is per call and not saved, except as a shared PNG.
- **Remove is not a ban:** a removed participant could rejoin a Meet now meeting from its card.
- **Time zones:** recurrence steps in local time; colleagues in different time zones (not expected on one office LAN) would see occurrences at the organiser's clock time.
